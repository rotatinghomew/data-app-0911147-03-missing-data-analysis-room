# 分析资料与解释边界

## 字段规则
schema 声明变量类型、上下界、类别、适用条件和派生关系。hours 的范围为零至六十，part_a 与 part_b 的和为 score。没有加入项目的学生，其 lab_hours 不适用，而非未知零工时。missing_reasons 分别记录 not_asked、refused、lost，未出现缺失原因的空值属于资料错误。
## 使用边界
需要支持均值、两组差异和带协变量的解释模型，让填补适配所选分析，合并点估计与方差而不拼接补全表计算普通标准误。可配置可解释的偏移类敏感性假设，无法从记录判断机制时不声称已验证随机缺失。填补数和随机种子属于分析资料，不能据结果挑种子。
## 对照情形
无缺失资料应回到普通分析；只有结构性空白的字段不得被补造。人工构造的多份估计可以独立核对合并方差。拒答与低成绩相关的资料用于检查敏感性，而不是要求某一方向的结论；分项与总分不能独立填出矛盾。
